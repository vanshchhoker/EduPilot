How to run on Windows
---------------------
1. Extract this ZIP to a new folder.
2. Open that extracted folder in VS Code (File > Open Folder).
3. Open Terminal > New Terminal.
4. Run: npm.cmd install
5. After install completes, run: npm.cmd run dev
6. Open the localhost URL shown in the terminal (normally http://localhost:5173/).

Why npm.cmd?
------------
In Windows PowerShell, npm.ps1 may be blocked by script execution policy. Using npm.cmd
runs the Windows command shim and avoids that specific PowerShell script error.

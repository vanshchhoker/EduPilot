EDUPILOT SMART CAMPUS — ULTIMATE EDITION

RUN ON WINDOWS:
1. Extract ZIP into a NEW folder.
2. Open extracted folder in VS Code.
3. Terminal > New Terminal.
4. Run: npm.cmd install
5. Run: npm.cmd run dev
6. Open the localhost URL printed by Vite.

FEATURES:
- Overview, EduCoins demo wallet and rewards.
- Marketplace with camera/photo upload and demo buy request.
- EduPlay coding quiz and mini-games.
- Community posts with photo upload/camera.
- Demo student signup/login.
- Campus Clubs directory and interest action.
- Faculty Doubt Desk with weekly availability and last-accepted time.
- Smart ID digital student profile (not official ID).
- Event Radar with sample events and local interest registration.
- Skill Exchange for student-to-student learning.
- Voice of Students feedback/issue reporting.
- Smart Study Planner for assignments and deadlines.
- Campus SOS guidance with India emergency number 112.
- Campus Life retains the original map/gallery/Lost & Found.
- Local FAQ-style AI assistant.

IMPORTANT LIMITATIONS:
- This is a hackathon front-end prototype. App data is stored in localStorage on the current browser/device. It is not a live shared campus system.
- Login is demo-only and insecure; do not use real or reused passwords. Production requires secure server-side authentication, password hashing, role-based access and data protection.
- Digital ID is not an official CGC identity card or scannable access pass.
- Events, clubs, member counts, faculty names and doubt slots are sample/illustrative. Verify all real details with CGC University before publishing.
- Club interest, event registration, skill exchange and doubt requests are local demo actions, not sent to actual staff/students.
- Feedback is not delivered to university administration. Real anonymous feedback needs a secure backend and moderation.
- SOS does not dispatch alerts or share location. In immediate danger in India, call 112 and verified campus security.
- Map, gallery and map tiles require internet; facility pins may be approximate.
- EduCoins are demo points, not money. Real vouchers/discounts need university/vendor partnerships and admin approval.
- Marketplace does not process payments. Arrange safe public meetups and verify items.
- AI Assistant is a local FAQ helper, not a connected generative AI. Real AI requires a secure server-side API integration.
- Browser storage can fill if large photos are uploaded. A production version needs cloud storage and a database.

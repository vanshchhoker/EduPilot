
# 🚀 EDUPILOT
### One Platform. Every Campus Need.

**Built by Team OSCAR**

EduPilot is a smart campus companion that brings student services, campus activities, communication and engagement into one unified platform.

## 🎯 Problem
Students use multiple disconnected platforms to access campus information, discover events, connect with peers and manage college activities.

## 💡 Our Solution
EduPilot provides one unified digital platform for everyday campus needs.

## ✨ Features
- Smart Campus ID
- Event Radar
- Campus Clubs
- Faculty Doubt Desk
- Marketplace
- Lost & Found
- Student Community
- Skill Exchange
- Voice of Students
- Study Planner
- EduCoins
- EduPlay
- Leaderboard
- Campus SOS
- Campus Map
- Gallery
- FAQ Assistant
- Notifications
- Admin Dashboard

## 🛠️ Tech Stack
- React
- JavaScript
- Vite
- CSS
- Lucide React

## 💻 Installation

Clone the repository:

`git clone https://github.com/vanshchhoker/EduPilot.git`

Open project folder:

`cd EduPilot`

Install dependencies:

`npm install`

Start the application:

`npm run dev`
